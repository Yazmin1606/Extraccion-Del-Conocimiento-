## Descripción General

Este repositorio contiene los laboratorios y prácticas desarrollados durante la asignatura de Extracción del Conocimiento de Base de Datos. 
Se realizaron actividades relacionadas con el análisis de datos, procesamiento de información, generación de datos sintéticos
y evaluación de resultados utilizando Python y diversas librerías especializadas.

## Objetivo
Aplicar técnicas de extracción y análisis de datos para obtener conocimiento útil a partir de conjuntos de datos,
empleando herramientas de ciencia de datos y minería de datos.

## Datasets Utilizados

- Archivos CSV almacenados en la carpeta Data.
- Datos sintéticos generados mediante la librería SDV.
- Conjuntos de datos utilizados en los distintos laboratorios.

## Herramientas Utilizadas
  
  - Python
- Jupyter Notebook
- Pandas
- NumPy
- SDV
- SDMetrics
- GitHub

## Instrucciones de Ejecución

1. Clonar el repositorio.
2. Instalar las dependencias necesarias.
3. Abrir Jupyter Notebook.
4. Ejecutar los archivos contenidos en la carpeta Notebooks.
